# Security policy

This repository is a **curated notes collection**. Every referenced finding is already public.

## Do not file undisclosed bugs here

- Do not add in-scope bounty findings, private reports, or unpatched issues.
- Corrections to classification or broken links: open a pull request or email **dersefurkan32@gmail.com**.
- Vulnerabilities in RISC Zero, SP1, or an integrator belong in **that** vendor’s disclosure channel, not in this repo.

## Use

These notes are for authorized review work and education. They are not permission to test third-party systems.
